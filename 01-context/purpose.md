# Purpose

For anyone building a Claude Code mod: the mod API on one public page per
Claude Code version, and a diff between versions, made from the declaration
file the engine writes beside every mod. The page is what the file lists;
nothing is judged or explained beyond its names and signatures.

Not for: a copy of the declaration file or its comments (Anthropic's; the
engine writes it for you), advice on migrating, or anything that runs inside
Claude Code.

Why it exists: a reference extracted from Claude Code's own files is the one
kind of repo in this lane with a counted record of readers; the index also
sends its readers to the mods and the kit built beside it.

Kill: no stranger's star, fork, watch or issue on the repo by 2026-11-12, or
an official per-version reference appears first.
